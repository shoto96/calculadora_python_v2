## ✨ Sobre o Projeto

Uma **calculadora completa em Python**, desenvolvida com foco em simplicidade, praticidade e versatilidade.

💡 O projeto oferece **duas formas de uso**:

* 🖥️ Interface gráfica moderna (GUI)
* 💻 Execução direta no terminal (CLI)

---

## 🚀 Funcionalidades

✔️ Operações matemáticas básicas
✔️ Funções avançadas com `math`
✔️ Interface gráfica com `Tkinter`
✔️ Execução rápida via terminal
✔️ Código limpo e organizado

---

## 📁 Estrutura do Projeto

```bash
📦 calculadora-python
 ┣ 📜 README.md
 ┣ 📜 instrucoes.txt
 ┣ 🖥️ calculadora_gui.py
 ┗ 💻 calculadora_cli.py
```

## ▶️ Como Executar

### 🖥️ Interface Gráfica (Recomendado)

```bash
python calculadora_gui.py
```

### 💻 Modo Terminal

```bash
python calculadora_cli.py
```
